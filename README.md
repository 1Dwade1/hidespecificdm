# HideSpecificDM

Плагин для BetterDiscord, который скрывает выбранных пользователей из списка личных сообщений.

## Возможности

- Скрытие конкретных пользователей из списка ЛС
- Поиск пользователей по имени или ID
- Визуальная панель управления скрытыми пользователями
- Сохранение настроек между перезапусками Discord

## Установка

1. Убедитесь, что у вас установлен [BetterDiscord](https://betterdiscord.app/)
2. Скачайте файл `HideSpecificDM.plugin.js`
3. Поместите файл в папку с плагинами BetterDiscord:
   - Windows: `%AppData%\BetterDiscord\plugins`
   - macOS: `~/Library/Application Support/BetterDiscord/plugins`
   - Linux: `~/.config/BetterDiscord/plugins`
4. Перезапустите Discord или перезагрузите плагины

## Использование

### Добавление пользователя в список скрытых

1. Откройте настройки Discord → Плагины → HideSpecificDM → Настройки
2. В поле поиска введите имя пользователя или ID
3. Выберите нужного пользователя из выпадающего списка или нажмите Enter, если вводили ID
4. Пользователь будет добавлен в список скрытых и исчезнет из списка ЛС

### Возврат пользователя в список ЛС

1. Откройте настройки плагина
2. Найдите пользователя в списке скрытых
3. Нажмите кнопку ✕ справа от имени пользователя
4. Пользователь снова появится в списке ЛС

## Рекомендации

### Использование вместе с функцией игнорирования Discord

Для полного контроля над нежелательными сообщениями рекомендуется использовать плагин **в связке с нативной функцией игнорирования Discord**:

#### Как игнорировать пользователя в Discord:

1. Правый клик по пользователю в списке друзей или ЛС
2. Выберите **"Игнорировать"**
3. Пользователь будет игнорирован, но останется видимым в списке ЛС

#### Комбинированное использование:

- **Игнорирование** → убирает уведомления, звуки, бейджи с иконкой сервера
- **HideSpecificDM** → убирает чат из списка ЛС визуально

## Технические детали

- Плагин использует CSS для скрытия элементов
- Fallback механизм через DOM для надежности
- Автоматическое обновление списка каждые 2 секунды
- Данные сохраняются в BetterDiscord storage

## Требования

- Discord Desktop (Windows/macOS/Linux)
